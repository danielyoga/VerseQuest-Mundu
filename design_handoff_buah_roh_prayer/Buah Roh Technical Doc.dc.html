Buah Roh Prayer Streak: implementation guide

Ready-to-paste code for the prayer page (design 4c) and the Amen fruit card (design 3c, "Fajar menyingsing"). Stack: Next.js App Router, Tailwind, Framer Motion, and localStorage only. Every value matches Buah Roh Prayer Final.
